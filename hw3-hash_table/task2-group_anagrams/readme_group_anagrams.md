## Описание решения

Алгоритм основан на использовании словаря для группировки слов, которые состоят из одинакового набора букв. Ключевая идея заключается в том, чтобы сопоставить каждой строке уникальный ключ, который будет одинаковым для всех её анаграмм.

Сперва мы определяем константы для размера алфавита и символа отсчета:
```python
ALPHABET_SIZE = 26
FIRST_LITERAL_CHAR = 'a'
```

Для вычисления ключа каждого слова используется вспомогательная функция `unordered_string_hash`. Она создает массив из 26 нулей (по количеству букв в английском алфавите):
```python
def unordered_string_hash(word: str) -> Hashable:
    hash = [0] * ALPHABET_SIZE
    word = word.lower()
    for char in word:
        hash[ord(char) - ord(FIRST_LITERAL_CHAR)] += 1
    return tuple(hash)
```
Функция проходит по каждому символу слова, вычисляет его индекс относительно буквы `a` (используя ASCII-коды) и увеличивает счетчик на 1. Итоговый массив преобразуется в кортеж (`tuple`), так как списки в Python нехешируемы и не могут быть ключами словаря.

В основной функции `group_anagrams` мы инициализируем словарь `hash_to_group`, где значениями по умолчанию будут пустые списки:
```python
def group_anagrams(words: list[str]) -> list[list[str]]:
    hash_to_group = defaultdict(list)
```

Далее мы проходим по всем словам из входного массива `words`. Для каждого слова вычисляется его частотный кортеж, который используется в качестве ключа. Само слово добавляется в список по этому ключу:
```python
    for word in words:
        hash_to_group[unordered_string_hash(word)].append(word)
```

В конце функция возвращает список всех сгруппированных значений словаря:
```python
    return list(hash_to_group.values())
```

**Оценка временной сложности алгоритма:** $O(N \cdot K)$, где $N$ — количество строк во входном массиве, а $K$ — максимальная длина строки. Для каждого из $N$ слов мы совершаем проход по всем его $K$ символам, чтобы вычислить частотный кортеж. Это оптимальнее, чем $O(N \cdot K \log K)$ при подходе с сортировкой каждого слова.
**Оценка сложности алгоритма по памяти:** $O(N \cdot K)$ для хранения итогового массива со всеми сгруппированными строками, плюс $O(N)$ для хранения ключей-кортежей (каждый из которых занимает $O(1)$ памяти, так как имеет фиксированную длину 26).
