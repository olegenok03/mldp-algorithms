## Описание решения

Сперва инициализируем пустой словарь `residuals`, который будет для каждого ожидаемого остатка (второго слагаемого) хранить индексы первого:

```python
residuals = {}
```

Далее итерируемся по массиву `arr`, одновременно получая индекс `i` и само значение `num` с помощью функции `enumerate`. На каждой итерации мы проверяем, не является ли текущее число `num` остатком для одного из предыдущих элементов:

```python
for i, num in enumerate(arr):
    if num in residuals:
        return residuals[num], i
```

Если текущее число `num` найдено в ключах словаря `residuals`, это означает, что пара найдена. Мы возвращаем индекс первого числа (сохраненный в словаре по ключу `num`) и текущий индекс `i`. Очевидно, они уже расположены по возрастанию.

Если числа в словаре нет, мы вычисляем остаток (разность `k - num`, т.е. число, которое в сумме с `num` даст целевое значение `k`) и сохраняем его в словарь как ключ, а текущий индекс `i` - как значение:

```python
    residuals[k - num] = i
```

По условию задачи существует ровно одна искомая пара, но, чтобы Ruff не ругался, по выходу из цикла выбрасывается исключение:

```python
raise ValueError('Summands have not found')
```

Оценка временной сложности алгоритма: $O(N)$, где $N$ - длина массива `arr`. В Python поиск ключа в словаре и добавление элемента в среднем занимают $O(1)$ времени. Мы проходим по массиву ровно один раз.
Оценка сложности алгоритма по памяти: $O(N)$. В худшем случае (если искомая пара находится в самом конце массива) мы сохраним в словарь $N - 1$ элементов.
