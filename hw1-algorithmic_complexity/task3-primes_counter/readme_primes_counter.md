## Описание решения

Стандартная задача на знание алгоритма решета Эратосфена. Сперва отсекаем случай `max_num <= 2`: для него функция должна возвращать $0$.
```python
if max_num <= 2:
    return 0
```

Идея алгоритма заключается в том, что мы последовательно помечаем, как составные, все числа массива, кратные простым (непомеченным) числам, которые перебираем от наименьшего возможного до наибольшего возможного. Для удобства поиска чисел, кратных простым множителям, маска `is_prime` инициализируется по размеру отрезка `[0; max_num - 1]`, т.е. включает в рассмотрение числа $0$ и $1$, не являющиеся простыми. Теперь по индексу `i` в маске `is_prime` лежит флаг для числа `i` (доступ по индексу за $O(1)$ с хорошей константой, т.к. не пересчитываем индекс):

```python
is_prime = [True] * max_num
is_prime[0], is_prime[1] = False, False
```

Заметим, что для любого простого множителя $k$, меньшего `max_num`, но большего, чем квадратный корень из `max_num`, любые кратные ему числа на отрезке будут содержать простые множители, меньшие $k$. Таким образом, если для всех простых множетелей, меньших $k$, кратные им числа были помечены, как составные, сам $k$ имеет смысл рассматривать, пока он не больше квадратного корня из `max_num - 1`:

```python
for k in range(2, int((max_num - 1) ** 0.5) + 1):
    if is_prime[k]:
        ...
```

Также заметим, что если для некоторого непомеченного числа $q$ уже были рассмотрены меньшие кандидаты, а числа, кратные им, были помечены, как составные, то $q$ является простым, т.к. иначе мы бы пометили его, когда рассматривали один из его простых множителей.

Для любого простого (равносильно непомеченному в заданном порядке рассмотрения, как было отмечено выше) числа $p$ имеет смысл помечать только те кратные числа, которые больше $p ^ 2$, т.к. все остальные уже были помечены при рассмоторении предыдущих простых множителей. Получаем:

```python
for k in range(2, int((max_num - 1) ** 0.5) + 1):
    if is_prime[k]:
        for i in range(k * k, max_num, k):
            is_prime[i] = False
```

Возвращаем количество значений $True$ в маске:

```python
return sum(is_prime)
```

Оценка временной сложности алгоритма: $O(n * log(log(n)))$, где $n$ - это заданная правая граница. Поскольку для каждого простого числа мы рассматриваем ~ $n \div p$ кратных ему. Выносим $n$ за скобки и для общего числа операций получаем пропорциональную зависимость от $n$ и от суммы чисел, обратных последовательным простым до $n$. Из теории чисел известно, что сумма последовательности чисел, обратных к последовательным простым, пропорциональна $log(log(n))$.
Оценка сложности алгоритма по памяти: $O(n)$ дополнительной памяти на хранение маски.
