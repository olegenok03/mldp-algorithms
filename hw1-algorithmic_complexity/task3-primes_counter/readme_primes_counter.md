## Описание решения

Стандартная задача на знание алгоритма решета Эратосфена. Идея заключается в том, что мы последовательно помечаем, как составные, все числа массива, кратные простым (непомеченным) числам, которые перебираем от наименьшего возможного до наибольшего возможного. Для удобства поиска чисел, кратных простым множителям, маска is_prime инициализируется по размеру отрезка $[0; maxnum]$, т.е. включает в рассмотрение числа $0$ и $1$, не являющиеся простыми. Теперь по индексу i в маске is_prime лежит флаг для числа i (доступ по индексу за $O(1)$ с хорошей константой, т.к. не пересчитываем индекс):

```python
is_prime = [True for _ in range(max_num + 1)]
is_prime[0], is_prime[1] = False, False
```

Заметим, что для любого простого множителя $k$, меньшего max_num, но большего, чем квадратный корень из max_num, любые кратные ему числа на отрезке будут содержать простые множители, меньшие $k$. Таким образом, если для всех простых множетелей, меньших $k$, кратные им числа были помечены, как составные, сам $k$ имеет смысл рассматривать, пока он не больше квадратного корня из max_num: 

```python
for k in range(2, int(max_num ** (1 / 2)) + 1):
    if is_prime[k]:
        ...
```

Также заметим, что если для некоторого непомеченного числа $q$ уже были рассмотрены меньшие кандидаты, а числа, кратные им, были помечены, как составные, то $q$ является простым, т.к. иначе мы бы пометили его, когда рассматривали один из его простых множителей.

Для любого простого (равносильно непомеченному в заданном порядке рассмотрения, как было отмечено выше) числа $p$ имеет смысл помечать только те кратные числа, которые больше $p ^ 2$, т.к. все остальные уже были помечены при рассмоторении предыдущих простых множителей. Получаем:

```python
for k in range(2, int(max_num ** (1 / 2)) + 1):
    if is_prime[k]:
        for i in range(k * k, max_num + 1, k):
            is_prime[i] = False
```

Возвращаем количество значений $True$ в маске:

```python
return sum(is_prime)
```

Оценка временной сложности алгоритма: $O(n * log(log(n)))$, где $n$ - это заданная правая граница. Подготовлю объяснение к экзамену, но сейчас очень хочется спать.
