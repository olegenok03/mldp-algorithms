## Описание решения

Сперва определяем разрядность числа (кол-во разрядов в десятичной записи): 

```python
ord_num = int(log10(a)) + 1
```
Исходное число по условию положительно, поэтому функция log10 отработает корректно.

Для неотрицательных значений логарифма ($a \geq 1$ по условию) отброс дробной части с помощью int эквивалентен округлению вниз до ближайшего целого.

Далее проверяем равенство цифр в записи числа, итерируясь одновременно по левой половине слева направо и по правой половине справа налево. Если разрядность нечетная, цифра по центру не рассматривается:

$$ i = 0...[ordnum \div 2]$$

```python
left_i = (a // 10 ** i) % 10
right_i = (a // 10 ** (ord_num - i - 1)) % 10
```

Если встретили пару различных цифр, возвращаем $False$. По выходу из цикла возвращаем $True$.
