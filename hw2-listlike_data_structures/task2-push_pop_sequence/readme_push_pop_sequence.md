## Описание решения

Для решения задачи моделируется работа реального стека с помощью обычного списка `stack`. Помимо него, инициализируются два указателя: `i` - для обхода массива `pushed`, и `j` - для массива `popped`. Переменная `n` хранит размер массивов.

```python
stack = []
i, j = 0, 0
n = len(pushed)
```

Далее запускается основной цикл `while`, который работает до тех пор, пока не будут обработаны все элементы (пока хотя бы один из указателей не достигнет конца массива: `i < n or j < n`). На каждой итерации алгоритм в строгом порядке проверяет, какую операцию можно совершить:

- **Pop (извлечение):** Если стек не пуст и элемент на его вершине (`stack[-1]`) совпадает с текущим ожидаемым элементом из `popped[j]`, элемент удаляется из стека, а указатель `j` сдвигается вперед. Эта проверка идет первой, так как жадное извлечение элементов при совпадении гарантирует правильный порядок.
- **Push (добавление):** Если извлечь элемент нельзя, но в массиве `pushed` еще остались необработанные элементы (`i < n`), текущий элемент `pushed[i]` помещается в стек, а указатель `i` увеличивается.
> Если элемент на вершине не совпадает с ожидаемым, а добавлять в стек больше нечего, то требуемую последовательность получить невозможно. Алгоритм возвращает `False`.

```python
while i < n or j < n:
    if stack and stack[-1] == popped[j]:
        stack.pop()
        j += 1
    elif i < n:
        stack.append(pushed[i])
        i += 1
    else:
        return False
return True
```

Если цикл успешно завершает свою работу, т.е. все элементы были успешно помещены в стек и извлечены из него в нужной последовательности, то функция возвращает `True`.

**Оценка временной сложности алгоритма:** $O(n)$, где $n$ - длина массива `pushed`. Каждый элемент добавляется в стек ровно один раз и извлекается из него не более одного раза. Следовательно, цикл выполнит максимум $2n$ итераций.
**Оценка сложности алгоритма по памяти:** $O(n)$ в худшем случае. Если последовательность операций требует сначала положить все элементы, а только потом начать их извлекать, то размер массива `stack` будет равен $n$. Дополнительные переменные `i`, `j`, `n` требуют $O(1)$ памяти.
