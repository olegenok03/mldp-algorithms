# Бинарное дерево поиска: вставка и обходы

## 1. Метод вставки узла (`insert`)

Бинарное дерево поиска (BST) обладает свойством: для любого узла с ключом $K$ все ключи в левом поддереве строго меньше $K$, а в правом — строго больше $K$.

Метод `insert` реализован **итеративно**, без рекурсии, что гарантирует работу за $O(1)$ дополнительной памяти и отсутствие риска переполнения системного стека (`RecursionError`).

### Код метода

```python
def insert(self, key: int) -> None:
    if self.root is None:
        self.root = TreeNode(key)
        return

    curr = self.root
    while True:
        if key < curr.key:
            if curr.left is None:
                curr.left = TreeNode(key)
                return
            curr = curr.left
        elif key > curr.key:
            if curr.right is None:
                curr.right = TreeNode(key)
                return
            curr = curr.right
        else:
            # Ключ уже присутствует в BST (дубликаты игнорируются)
            return
```

### Логика работы
1. **Пустое дерево:** Если корень отсутствует (`self.root is None`), создаём `TreeNode(key)` и делаем его корнем дерева.
2. **Поиск позиции:** Инициализируем указатель `curr = self.root` и в цикле спускаемся по дереву:
   - Если вставляемый `key < curr.key`, то согласно инварианту BST новый узел должен находиться в левом поддереве:
     - Если `curr.left is None`, мы нашли подходящее место — создаём новый узел `curr.left = TreeNode(key)` и завершаем выполнение.
     - Иначе перемещаем указатель влево: `curr = curr.left`.
   - Если `key > curr.key`, новый узел должен находиться в правом поддереве:
     - Если `curr.right is None`, создаём новый узел `curr.right = TreeNode(key)` и завершаем выполнение.
     - Иначе перемещаем указатель вправо: `curr = curr.right`.
   - Если `key == curr.key`, ключ уже присутствует в дереве. По стандартному соглашению множеств дубликаты повторно не вставляются.

### Оценка сложности
- **Временная сложность:** $O(H)$, где $H$ — высота дерева.
  - В сбалансированном дереве $H = O(\log N)$.
  - В худшем случае (вырожденное в линию дерево) $H = O(N)$.
- **Пространственная сложность:** $O(1)$ дополнительной памяти (алгоритм итеративный, используются только локальные ссылки).

### Визуализация вставки

Рассмотрим вставку ключа `5` в существующее BST:

```text
    Дерево ДО вставки ключа 5:            Дерево ПОСЛЕ вставки ключа 5:

               4                                        4
             /   \                                    /   \
            2     6                                  2     6
           / \                                      / \   /
          1   3                                    1   3 5
```

| Шаг | Текущий узел `curr` | Сравнение ключей | Ветка `if/elif` | Наличие потомка | Выполняемое действие |

## 2. Методы обхода дерева (Traversals)

В бинарном дереве поиска обходы определяют порядок посещения узлов:
- **Pre-order** (прямой): `Корень` $\to$ `Левое поддерево` $\to$ `Правое поддерево` ($N \to L \to R$)
- **In-order** (симметричный): `Левое поддерево` $\to$ `Корень` $\to$ `Правое поддерево` ($L \to N \to R$)
- **Post-order** (обратный): `Левое поддерево` $\to$ `Правое поддерево` $\to$ `Корень` ($L \to R \to N$)

Все три метода реализованы **итеративно** с использованием единого паттерна — **указателя текущего узла `curr` и явного стека `tree_stack`**.

---

### Метод `get_preorder` (Прямой обход)

При прямом обходе каждый узел должен быть обработан **до** перехода к его потомкам.

```python
def get_preorder(self) -> list[int]:
    res = []
    tree_stack = []
    curr = self.root

    while curr is not None or tree_stack:
        if curr is not None:
            res.append(curr.key)
            tree_stack.append(curr)
            curr = curr.left
        else:
            curr = tree_stack.pop()
            curr = curr.right

    return res
```

**Логика работы:**
1. Пока `curr` указывает на узел, мы сразу добавляем его ключ в `res` (`res.append(curr.key)`), сохраняем узел в стек, чтобы позже вернуться к его правому поддереву, и спускаемся влево: `curr = curr.left`.
2. Когда доходим до конца ветки (`curr is None`), извлекаем верхний узел из стека (`curr = tree_stack.pop()`) и переключаемся на его правого потомка: `curr = curr.right`.

**Оценка сложности:**
- **Время:** $O(N)$, где $N$ — число узлов в дереве. Каждый узел попадает в стек и извлекается ровно один раз.
- **Память:** $O(H)$, где $H$ — высота дерева ($O(\log N)$ в сбалансированном дереве, $O(N)$ в худшем вырожденном случае).

---

### Метод `get_inorder` (Симметричный обход)

При симметричном обходе узел обрабатывается **после** того, как всё его левое поддерево уже пройдено, но **до** перехода в правое поддерево. Для BST этот обход возвращает ключи в строго отсортированном порядке по возрастанию.

```python
def get_inorder(self) -> list[int]:
    res = []
    tree_stack = []
    curr = self.root

    while curr is not None or tree_stack:
        if curr is not None:
            tree_stack.append(curr)
            curr = curr.left
        else:
            curr = tree_stack.pop()
            res.append(curr.key)
            curr = curr.right

    return res
```

**Логика работы:**
1. Мы спускаемся влево до упора, складывая узлы в стек, но **не записывая** их в `res`.
2. При достижении тупика (`curr is None`) извлекаем последний пройденный узел из стека: `curr = tree_stack.pop()`.
3. Левое поддерево узла гарантированно обработано — записываем ключ в результат: `res.append(curr.key)`.
4. Переходим к правому потомку: `curr = curr.right`.

**Оценка сложности:**
- **Время:** $O(N)$, каждый узел посещается константное число раз.
- **Память:** $O(H)$, глубина стека определяется максимальной высотой дерева.

---

### Метод `get_postorder` (Обратный обход)

При обратном обходе узел обрабатывается в последнюю очередь — **после** полного обхода как левого, так и правого поддеревьев.

```python
def get_postorder(self) -> list[int]:
    res = []
    tree_stack = []
    curr = self.root
    last_visited = None

    while curr is not None or tree_stack:
        if curr is not None:
            tree_stack.append(curr)
            curr = curr.left
        else:
            peek_node = tree_stack[-1]
            if peek_node.right is not None and last_visited != peek_node.right:
                curr = peek_node.right
            else:
                res.append(peek_node.key)
                last_visited = tree_stack.pop()

    return res
```

**Логика работы:**
1. Спускаемся влево до упора, складывая узлы в стек.
2. При достижении `curr is None` узел нельзя сразу извлекать из стека (`pop`), так как сначала нужно обойти его правое поддерево. Проверяем вершину стека через `peek_node = tree_stack[-1]`.
3. Если правый потомок существует и мы ещё не приходили из него (`last_visited != peek_node.right`), переходим в него: `curr = peek_node.right`.
4. Если правого потомка нет или мы только что вернулись из него (`last_visited == peek_node.right`), значит, оба поддерева обработаны:
   - Добавляем значение в результат: `res.append(peek_node.key)`.
   - Извлекаем узел из стека и запоминаем его как последний обработанный: `last_visited = tree_stack.pop()`.
   - `curr` остаётся `None`, чтобы на следующей итерации проверить следующего родителя в стеке.

**Оценка сложности:**
- **Время:** $O(N)$, каждый узел помещается в стек один раз и просматривается не более 2 раз.
- **Память:** $O(H)$, глубина стека ограничена высотой дерева $H$.
