# Задача 3. Balanced Binary Tree

## Описание решения

В задаче требуется определить, является ли бинарное дерево сбалансированным по высоте.

Бинарное дерево считается **сбалансированным по высоте** (по определению AVL-дерева), если для **каждого** узла дерева высоты его левого и правого поддеревьев отличаются не более чем на 1:

$$|h_{left} - h_{right}| \le 1$$

В решении представлены два взаимодополняющих подхода:
1. **Рекурсивный подход** — лаконичная каноническая реализация через обход снизу вверх (bottom-up) со сторожевым значением `-1`.
2. **Итеративный подход** — надёжная промышленная реализация на базе стека фреймов вызовов, гарантирующая защиту от переполнения стека (`RecursionError`) на экстремально глубоких вырожденных деревьях (например, при высоте $5000+$).

---

## Вариант 1. Рекурсивное решение со сторожевым значением (`-1`)

### Идея алгоритма
Наивный подход, вызывающий функцию подсчёта высоты отдельно для каждого узла сверху вниз, работает за $O(N^2)$, так как многократно пересчитывает одни и те же поддеревья.

Оптимальное решение вычисляет высоту снизу вверх (bottom-up / post-order) за **один проход** ($O(N)$):
- Вспомогательная функция `check_height(node)` возвращает неотрицательную **высоту** поддерева ($0, 1, 2, \dots$), если оно сбалансировано.
- Если в поддереве обнаружен дисбаланс, функция возвращает специальный маркер ошибки — сторожевое значение (sentinel value) **`-1`**.
- **Ранний выход (Short-Circuiting):** если левое поддерево вернуло `-1`, правое поддерево даже не начинает обходиться — вызов немедленно возвращает `-1` вверх по стеку вызовов.

### Код рекурсивного метода

```python
def is_balanced_recursive(tree: BinarySearchTree) -> bool:
    def check_height(node: TreeNode | None) -> int:
        if node is None:
            return 0

        left_height = check_height(node.left)
        if left_height == -1:
            return -1  # Дисбаланс слева — немедленный откат наверх

        right_height = check_height(node.right)
        if right_height == -1:
            return -1  # Дисбаланс справа — немедленный откат наверх

        if abs(left_height - right_height) > 1:
            return -1  # Дисбаланс в текущем узле

        return 1 + max(left_height, right_height)

    return check_height(tree.root) != -1
```

### Оценка сложности
- **Временная сложность:**
  - В худшем случае (дерево сбалансировано): $O(N)$, где $N$ — число узлов в дереве.
  - При наличии дисбаланса: $O(K)$, где $K$ — число узлов, посещённых до первого обнаруженного нарушения ($1 \le K \le N$). Если дисбаланс находится в левом поддереве корня, правое поддерево корня не обходится вовсе. Если же дисбаланс в правом поддереве корня, левое поддерево будет пройдено целиком ($K$ порядка $N$).
- **Пространственная сложность:** $O(H)$, где $H$ — высота дерева ($O(\log N)$ в сбалансированном дереве, $O(N)$ в вырожденном). Память расходуется на системный стек вызовов Python. На вырожденных деревьях с $H \ge 1000$ вызывает `RecursionError`.

## Вариант 2. Итеративное решение через стек фреймов вызовов

### Идея алгоритма
Чтобы устранить фундаментальное ограничение рекурсии по глубине стека Python (`sys.getrecursionlimit()`), мы эмулируем механизм выполнения функций через явный программный стек:
- В стеке `stack` хранятся фреймы вида: `[node, left_height, state]`.
- Переменная `ret_height` играет роль регистра возвращаемого значения (return value).
- Поле `state` отслеживает стадию обработки текущего узла:
  - **`state = 0`**: вход в узел $\to$ смена на `state = 1`, спуск в `node.left`.
  - **`state = 1`**: возврат из левого потомка $\to$ фиксация `left_height = ret_height`, смена на `state = 2`, спуск в `node.right`.
  - **`state = 2`**: возврат из правого потомка $\to$ получение `right_height = ret_height`.  
    Проверка инварианта: если $|left\_height - right\_height| > 1$, немедленно возвращаем `False`.  
    Иначе вычисляем высоту узла $ret\_height = 1 + \max(left\_height, right\_height)$ и снимаем узел из стека (`stack.pop()`).

### Код итеративного метода

```python
def is_balanced_iterative(tree: BinarySearchTree) -> bool:
    if tree.root is None:
        return True

    # Элемент стека: [node, left_height, state]
    stack: list[list] = [[tree.root, 0, 0]]
    ret_height = 0

    while stack:
        frame = stack[-1]
        node, left_height, state = frame

        if state == 0:
            frame[2] = 1
            if node.left is not None:
                stack.append([node.left, 0, 0])
            else:
                ret_height = 0
        elif state == 1:
            frame[1] = ret_height
            frame[2] = 2
            if node.right is not None:
                stack.append([node.right, 0, 0])
            else:
                ret_height = 0
        else:
            right_height = ret_height
            if abs(left_height - right_height) > 1:
                return False
            ret_height = 1 + max(left_height, right_height)
            stack.pop()

    return True
```

### Оценка сложности
- **Временная сложность:**
  - В худшем случае: $O(N)$, каждый узел посещается константное число раз.
  - При наличии дисбаланса: $O(K)$, где $K$ — число посещенных узлов до точки дисбаланса ($1 \le K \le N$).
- **Пространственная сложность:** $O(H)$, где $H$ — высота дерева. Память выделяется только под список фреймов в куче, что позволяет легко обрабатывать деревья с глубиной $10^5$ и более.

## Визуализация решения

В качестве наглядного нетривиального примера рассмотрим дерево со структурой, построенной по ключам `[8, 3, 1, 6, 4, 7, 10, 14, 13]`:

```text
               8
            /     \
           3       10
          / \        \
         1   6        14
            / \       /
           4   7     13
```

### Анализ баланса дерева:
1. **Левое поддерево корня (узел 8):**
   - Узлы `1`, `4`, `7`: листья, высоты $= 1$.
   - Узел `6`: $h_L(4)=1, h_R(7)=1 \implies |1 - 1| = 0 \le 1$, высота $h(6) = 2$.
   - Узел `3`: $h_L(1)=1, h_R(6)=2 \implies |1 - 2| = 1 \le 1$, высота $h(3) = 3$.
   Левое поддерево **полностью сбалансировано** и имеет высоту 3.
2. **Правое поддерево корня:**
   - Для узла `10`: левый потомок отсутствует ($h_L = 0$), а правое поддерево (узлы 14 и 13) имеет высоту $h_R = 2$.
   - **Разность высот в узле 10:** $|0 - 2| = 2 > 1$ — **обнаружен дисбаланс!**
3. **Ранний выход:** значение `-1` возникает в узле 10 и немедленно возвращается в корень 8. Само дерево в целом признаётся несбалансированным (`False`).
