# Задача 3. Balanced Binary Tree

## Описание решения

В задаче требуется определить, является ли произвольное бинарное дерево сбалансированным по высоте.

Бинарное дерево считается **сбалансированным по высоте** (по определению AVL-дерева), если для **каждого** узла дерева высоты его левого и правого поддеревьев отличаются не более чем на 1:

$$|h_{left} - h_{right}| \le 1$$

---

### Идея рекурсивного Bottom-Up обхода со сторожевым значением (`-1`)

1. **Почему не наивный рекурсивный подход ($O(N^2)$)?**
   В наивном решении для каждого узла вызывается отдельная функция `height(node)`. Это приводит к тому, что поддеревья обходятся многократно: для родителя, затем для его детей, затем для внуков и т.д. В худшем случае на вырожденном дереве сложность достигает $O(N^2)$.

2. **Изящное совмещение проверки и вычисления высоты за один проход ($O(N)$):**
   Мы используем обход снизу вверх (bottom-up / post-order), совмещая подсчёт высоты с валидацией баланса.
   
   Вспомогательная функция `check_height(node)` возвращает:
   - неотрицательное число ($0, 1, 2, \dots$) — реальную **высоту** поддерева, если оно сбалансировано;
   - специальное сторожевое значение (sentinel value) **`-1`**, если где-то в поддереве обнаружен дисбаланс.

3. **Ранний выход (Early Exit / Short-Circuiting):**
   - Если при рекурсивном вызове `left_height = check_height(node.left)` мы получили `-1`, нет никакого смысла проверять правое поддерево `node.right`. Мы мгновенно возвращаем `-1` наверх.
   - Аналогично, если `right_height == -1`, сразу возвращаем `-1`.
   - Если оба поддерева сбалансированы, проверяем разность их высот:
     $$\text{если } |left\_height - right\_height| > 1 \implies \mathbf{return\ -1}$$
   - Если всё в порядке, возвращаем честную высоту текущего узла:
     $$1 + \max(left\_height, right\_height)$$
   
   Итоговый результат: `return check_height(root) != -1`.

---

### Код решения

```python
def is_balanced(tree: BinarySearchTree) -> bool:
    def check_height(node: TreeNode | None) -> int:
        if node is None:
            return 0

        left_height = check_height(node.left)
        if left_height == -1:
            return -1

        right_height = check_height(node.right)
        if right_height == -1:
            return -1

        if abs(left_height - right_height) > 1:
            return -1

        return 1 + max(left_height, right_height)

    return check_height(tree.root) != -1
```

---

### Оценка сложности

- **Временная сложность:**
  - В худшем случае (дерево сбалансировано): $O(N)$, где $N$ — число узлов в дереве. Каждый узел посещается ровно один раз.
  - В лучшем / среднем случае (при обнаружении дисбаланса): $O(K)$, где $K \ll N$ — число узлов до первой точки дисбаланса (благодаря раннему выходу через `-1`).
- **Пространственная сложность:** $O(H)$, где $H$ — высота дерева ($O(\log N)$ в сбалансированном дереве, $O(N)$ в худшем вырожденном случае). Память расходуется только на системный стек вызовов функции `check_height`.

---

## Визуализация решения

### Пример 1. Сбалансированное дерево (Balanced Tree)

Рассмотрим бинарное дерево:

```text
        2
       / \
      1   3
```

Ожидаемый результат: `True`.

#### Трассировка рекурсивных вызовов `check_height`

| Шаг | Вызов для узла | `node.left` результат | `node.right` результат | Проверка $|h_L - h_R| \le 1$ | Возвращаемое значение |
|:---:|:--------------:|:---------------------:|:----------------------:|:----------------------------:|:---------------------:|
| 1   | `check_height(Node(2))` | ожидание... | — | — | — |
| 2   | `check_height(Node(1))` | `0` (`None`) | `0` (`None`) | $\|0 - 0\| = 0 \le 1$ | $1 + \max(0, 0) = \mathbf{1}$ |
| 3   | `check_height(Node(3))` | `0` (`None`) | `0` (`None`) | $\|0 - 0\| = 0 \le 1$ | $1 + \max(0, 0) = \mathbf{1}$ |
| 4   | Возврат в `Node(2)` | `left_height = 1` | `right_height = 1` | $\|1 - 1\| = 0 \le 1$ | $1 + \max(1, 1) = \mathbf{2}$ |
| 5   | Итог `is_balanced` | — | — | $2 \neq -1 \implies \mathbf{True}$ | **`True`** |

---

### Пример 2. Несбалансированное дерево с ранним выходом (Unbalanced Tree)

Рассмотрим вырожденное влево дерево ("бамбук"):

```text
       3
      /
     2
    /
   1
```

Ожидаемый результат: `False`.

#### Трассировка с фиксацией дисбаланса и откатом через `-1`

| Шаг | Вызов для узла | `node.left` результат | `node.right` результат | Проверка $|h_L - h_R| \le 1$ | Возвращаемое значение |
|:---:|:--------------:|:---------------------:|:----------------------:|:----------------------------:|:---------------------:|
| 1   | `check_height(Node(3))` | ожидание... | — | — | — |
| 2   | `check_height(Node(2))` | ожидание... | — | — | — |
| 3   | `check_height(Node(1))` | `0` (`None`) | `0` (`None`) | $\|0 - 0\| = 0 \le 1$ | $1 + \max(0, 0) = \mathbf{1}$ |
| 4   | Возврат в `Node(2)` | `left_height = 1` | `0` (`None`) | $\|1 - 0\| = 1 \le 1$ | $1 + \max(1, 0) = \mathbf{2}$ |
| 5   | Возврат в `Node(3)` | `left_height = 2` | `0` (`None`) | **$\|2 - 0\| = 2 > 1$** | **Дисбаланс! Возврат `-1`** |
| 6   | Итог `is_balanced` | — | — | $-1 \neq -1 \implies \mathbf{False}$ | **`False`** |

> **Обратите внимание:** Как только в узле `3` обнаружена разность высот, равная 2, функция немедленно вернула `-1`, не выполняя лишних обходов.
