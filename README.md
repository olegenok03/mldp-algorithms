# Клонирование репозитория
```powershell
git clone https://github.com/olegenok03/mldp-algorithms.git
```

# Установка зависимостей
Для установки глобальных зависимостей проекта рекомендуется воспользоваться пакетным менеджером pip версии 23.2.1 и новее. 
```powershell
pip install -r requirements.txt
```
Команды установки зависимостей для отдельных домашних заданий (если таковые зависимости есть) представлены в README-файлах в соответствующих директориях.

# Запуск проекта
Для запуска проекта требуется установленный Python версии 3.12.1 и новее. Команды запуска тестов решений представлены в README-файлах в директориях соответствующих домашних заданий.
